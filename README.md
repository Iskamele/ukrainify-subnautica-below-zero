## Про проєкт

Ми робимо повне українське озвучення Subnautica: Below Zero: усі сюжетні репліки, записи КПК, дзвінки й кат-сцени.
Разом із ним — субтитри під записаний текст і текстури з написами (постери, вивіски, екрани).

Обсяг, який гра справді програє:

| | |
|---|---|
| Реплік | ≈1 100 |
| Тривалість | ≈114 хв |
| Персонажів із голосом | ≈30 |

Найбільші ролі — Робін, Ал-Ан і Сем.
